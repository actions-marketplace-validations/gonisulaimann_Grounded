PART 3 — DECISION: WHAT WAS BUILT
────────────────────────────────────────────────────────────────
Name: grounded — the epistemic linter.
Tagline: "Prove your comments wrong — deterministically, offline, in ms."
Concept: every comment/docstring/JSDoc block is a set of falsifiable claims;
each claim is verified against the repo snapshot; provably-false claims
become findings with claim + evidence + fix. Severities: lie (error,
provable falsehood) > drift (warning, stale by evidence) > smell (note,
fragile, will rot). Default CI gate fails on lie.
Scope (MVP): Python + JS/TS, 8 checkers, 4 reporters, TOML config, zero
dependencies (stdlib only), no network/history/LLM by construction.

The 8 checkers:
1. stale-symbol-ref (lie/drift) — comment names foo() or `foo` with no
   definition anywhere in the repo.
2. stale-file-ref (lie) — comment names src/x/y.py that doesn't exist.
3. param-mismatch (lie/drift) — docstring params vs real signature
   (Google/NumPy/Sphinx/JSDoc).
4. raises-mismatch (drift) — documents `raises X` but body never raises.
5. return-mismatch (lie) — documents a return the body never returns
   (or claims void while returning).
6. number-drift (drift) — magic number in comment (timeout/port/limit/…)
   disagrees with adjacent code (±15 lines, bidirectional).
7. commented-code (drift) — run of comments parses as valid code
   (license/banner/directive guards).
8. fragile-anchor (smell) — `line 42` anchors, see-above/below, untracked
   HACK/XXX/workarounds, dateless temporal markers.

PART 4 — ARCHITECTURE & STACK
────────────────────────────────────────────────────────────────
Stack: Python 3.10+, stdlib only (ast, tokenize, re, argparse, tomllib).
Zero runtime dependencies. Installs anywhere, runs air-gapped.

Layout (src/grounded/):
- models.py — Finding / FileFacts / FuncInfo / Comment dataclasses.
- repo_index.py — repo-wide symbol table (ast for Python, regex for JS/TS:
  function/const-arrow/class/method/export patterns) + file resolver
  (rel paths, basenames, on-disk fallback).
- parsers.py — per-file facts. Python: ast (signature, value-return,
  raises via Raise walk, docstrings, is_method) + tokenize comments.
  JS/TS: regex comment scanner (// and /* */ incl. JSDoc * stripping,
  string-quote guard) + function extractor (function decl, arrow, function
  expression, class, method) with preceding-JSDoc linkage + body signals
  (value-return, throw New X) over an 80-line brace window.
- checkers.py — 8 checkers + docstring parsers + shared guards
  (builtins, JS globals, language KEYWORDS, English funcwords, placeholder
  path hints, reference verbs, dead-code cascade suppression set).
- scanner.py — recursive collection (ignore dirs/files, minified skip),
  index build, checker fan-out (one checker exception can never crash a
  scan), sorted findings.
- reporters.py — terminal (ANSI, grouped, summary), JSON, SARIF 2.1.0,
  self-contained HTML (inline CSS/JS filter, severity cards, escaping).
- cli.py — scan / init / explain / list; exit 1 when findings meet
  --fail-on (default lie), 0 otherwise, 2 on usage error.
- config.py — grounded.toml / .grounded.toml / pyproject [tool.grounded]
  via tomllib (enable/disable/ignore_dirs/ignore_files/fail_on).

Key design decisions:
- Snapshot-only: reproducible on any checkout/tarball; no git dependency.
- Precision over recall: backtick/verb gating, distinctive-name tiers,
  placeholder guards, stoplists, dead-code suppression; own tree scans clean.
- Evidence calculus: claim string + contradicting evidence + concrete fix.
